11. **`vcx.live`, unchanged.** A/B/C’s broker preserves readable feeds regardless of CORS headers. A script-enabled sandbox without `allow-same-origin` has an opaque origin. Direct `fetch` can read a cross-origin response if the server allows it through CORS. `no-cors` yields an opaque response with no readable body. E’s proposal therefore covers CORS-enabled endpoints only. Use a frame-bound message channel, scoped feed IDs, and explicit bindings for approved local feeds. **Recommendation**

Ship a virtualized transcript in today’s AppKit host, with one system WKWebView per session window.  
Keep the native composer and independent workers while validated template edits go live with rollback.  
Preserve agent charts through sandboxed frames and a scoped feed broker, and bundle standard chart assets offline.  
Gate rollout on a matched eight-window replay covering WebKit helpers, energy, and native input.  
Port the core and workers to Rust, then change the thin host only if doing so reduces maintenance.
